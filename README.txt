САЙТ «ИРЭН» — ОБНОВЛЁННЫЙ КОМПЛЕКТ

В архиве:
- index.html — исправленная разметка, единый booking modal, фотоблоки и SVG favicon link;
- style.css — исходный дизайн плюс адаптивная сетка, мобильные состояния, анимации и photo lightbox;
- мобильный первый экран дополнительно исправлен: кнопки компактные, без растяжения по высоте, информационная строка упорядочена;
- script.js — обработчики навигации, меню, фильтров, окон, фотогалереи и формы;
- favicon.svg — векторная favicon;
- images/README.txt — список фотографий, которые следует положить в папку images.

УСТАНОВКА
1. Распакуйте архив в папку сайта.
2. Сохраните или скопируйте из старой версии папку images с оригинальными фотографиями.
3. Не переименовывайте файл images/logo-iren.png — логотип оставлен прежним.
4. Загрузите содержимое папки на хостинг, заменив старые index.html, style.css и script.js.

ВАЖНО ПРО ЗАЯВКИ
В присланных исходниках не было серверного обработчика или API для форм. Поэтому форма теперь проверяет поля и открывает WhatsApp с уже заполненным текстом на номер +7 (908) 108-14-15. Пользователь должен подтвердить отправку внутри WhatsApp. Сообщение об успешной серверной отправке не показывается.

ВАЖНО ПРО ФОТО
В загрузке были только HTML, CSS и JavaScript. Оригинальная папка images не прилагалась, поэтому архив содержит файл-памятку, а не заменители ваших фотографий. Скопируйте старую папку images целиком — исходный логотип и фотографии подхватятся по прежним путям. До этого отсутствующие фото аккуратно заменяются нейтральными заглушками, а не сломанными иконками.
